This folder contains the scripts to generate gen3sis config files for all the scenarios tested in this study.

In the main folder, the scripts will generate the configs for the main analyses
In the additional folders, the configs generated are for the sensitivity analyses:
	- 'Equal_dist': standardising initial distances to the isthmus between NA and SA
	- 'Niche_expanded': expanding the thermal range of NA species (just for M0 and M1)
	- 'Oscillayers': replicating the main analyses in an Oscillayers-based landscape
