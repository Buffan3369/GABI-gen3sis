This folder contains the scripts used to design alternative gen3sis landscape based on palaeoclimate layers from Oscillayers (Gamish 2019 -- Global Ecology & Biogeography).

`0-Upscale_rasters.R` is the function that proceeds to the downscaling
`1-Process_climate_Oscillayers.R` processes climate rasters (executes previous script)


Additionally, `Comparison_plot.R` illustrates the consequence of the upscaling procedure on the resolution of the layers, and `Get_clim_coord_Americas.R` returns generates the xy dataframes with the coordinates of the 1x1° grid cells.
