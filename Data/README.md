This folder contains the data associated to the publication "Palaeoclimate alone fails to explain the asymmetry of the Great American Biotic Interchange.

These include:

* Simulation landscapes (`Gen3sis_landscapes/`)
* Config files for standard analyses, for each of the four modelling schemes, *i*.*e*., from M0 to M3 (`Gen3sis_configs-Standard_analyses/`)
* Config files for supplemental analyses after expanding the thermal niche breadth for simulations starting from North America, just for M0 and M1 (`Gen3sis_configs-Niche_expanded/`)

R scripts associated with data preprocessing, postprocessing and visualisation may be found here: <https://github.com/Buffan3369/GABI-gen3sis.git>
